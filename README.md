# SECR1013-Digital-Logic

## Summary 👍

This course has teach me a lot from the beginning of Numbering Systems such as binary, octal, decimal, and hexadecimal. All of this are essential for understanding how these digital systems can represent data. I also studied about Logic Gates which teaches about the differences in AND, OR, NOT, NAND, NOR, XOR, and XNOR. All of these logic gates basically are the basic building blocks of any digital circuit. With these building blocks, we can produce a truth table which can determine the output for any combination of different inputs. For Boolean Algebra, this topic efficiently teach me about how to design any complex circuit into much simpler ones. Therefore, my understanding of how digital systems operates has improved my skills for problem-solving, logical thinking, and patient which are extremely useful for my future work-force.

## Reflection for each assignments 🔍 

### Assigment 1 (LAB 1)

With all these labworks, I learn a lot about practical understanding of what I learned from inside the classroom. The 1st labwork tests our understanding in the usage of different types of ICs that’s been used. For example, we were given a picture of a schematic diagram and proceeded to find the output from the diagram itself by using the given ICs, wires, and breadboard inside the lab. I think this assignment is definitely useful to enhance my understanding in connection between different types of gates. Other than that, I also learn about the different position of legs of the ICS, like the exposition of VCC, Ground and more. Overall, this lab session let me learn deeper between Boolean algebra theory and the physical reality of digital hardware construction. I think one of the improvements that can be done is to install more different types of coloured wires with all types of length, short, medium, and long. Since there aren’t many options on the colours, I get confused easily while doing the lab work.

### Assignment 2 (LAB 2) 

For lab 2, I also learn the usage of different types of apps, which is called DEEDS (Digital Electronics Education and Design Suite), a software that’s been used as a platform to increase the understanding of prototyping using digital simulation. Using DEEDS helps me more in understanding the complex variety of system design. This software helps me attain more knowledge about bringing the reality of signal behaviour from the theoretical truth table itself. Other than that, it also helps me in figuring out the complicated design of given logic gates and the final output of the design itself. I think this course should apply the usage of the DEEDS app more to increase the understanding of students in the classroom.
