This course has teach me a lot from the beginning of Numbering Systems such as binary, octal, decimal, and hexadecimal. All of this are essential for understanding how these digital systems can represent data. Therefore, my understanding of how digital systems operates has improved my skills for problem-solving, logical thinking, and patient which are extremely useful for my future work-force.
